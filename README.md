# Shepit Studio

One window for every coding agent and account on your Mac: Claude Code sessions from all your accounts,
live chat, queue, permissions, Remote Control, limits and a terminal.

**Download:** [ShepitStudio.dmg](https://github.com/dmytrolakiza/shepit-studio-releases/releases/latest/download/ShepitStudio.dmg)

Requires macOS 14.2 or later on Apple Silicon. The app updates itself.

On first launch macOS may say it can't verify the developer: open **System Settings → Privacy & Security**
and click **Open Anyway** (once).

This repository only hosts release downloads.
